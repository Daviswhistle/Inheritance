# 상속 — 계약·수수료 검토 자료

소스 저장소: https://github.com/Daviswhistle/Inheritance

한국 미니앱 스토어 출시를 위해 배포된 상속 계약과 서비스 수수료를 검토해 주시기 바랍니다. 앱은 영어와 한국어를 지원합니다.

## 계약과 이용자 권한

World Chain 메인넷, 체인 ID 480입니다.

| 계약 | 주소 |
| --- | --- |
| WLD 팩토리 | `0xaC23bd1aF03ce3A178ac9dc54e0159005422F0ff` |
| USDC 팩토리 | `0xB3d5ead33a91287C2D39b345041D5a44dC381c5e` |
| Re7 WLD 전략 | `0x348831b46876d3dF2Db98BdEc5E3B4083329Ab9f` |
| Re7 USDC 전략 | `0xb1E80387EbE53Ff75a89736097D34dC8D9E9045B` |

상속 앱의 팩토리와 이용자 금고는 업그레이드할 수 없는 불변 계약입니다. 예치자가 수령인·연장 주기·출금을 직접 관리합니다. 개발자는 이용자 금고를 업그레이드하거나 자산을 압류하거나 수령인을 바꿀 수 없습니다. 서비스 수수료율과 수령 주소는 배포 시 고정됩니다.

연장 기한이 지나면 지정 수령인이 수령을 신청할 수 있고, 신청 후 7일이 지나면 지급할 수 있습니다. 소유자는 실제 지급이 실행될 때까지 기한을 연장해 신청을 취소할 수 있습니다. 자동 실행도 지정 수령인에게만 지급하며, 가스비 지원에는 별도의 운영 금고를 사용합니다.

상속 종료는 출금과 수령인 해제를 하나의 거래로 처리합니다. 실패하면 결합된 거래 전체가 되돌려집니다. 상속 정산 중 현금 회수가 실패하면 수령인에게 운용 지분을 대신 전달하며, 수령인은 유동성이 확보되는 대로 이를 현금화할 수 있습니다.

## 서비스 수수료

서비스 수수료는 운용 비용을 반영한 양의 이익의 10%입니다. 예치 원금은 수수료 계산에서 제외합니다. 이전 출금으로 확정된 손실이 있으면 같은 금고의 해당 자산에서 생긴 이후 이익에서 그만큼을 먼저 뺀 뒤 수익 수수료를 계산합니다.

- **현금 정산:** 실제 받은 자산을 기준으로 이익을 계산하고, 해당 자산으로 수수료를 받습니다.
- **지분 정산:** 전략 계약의 `convertToAssets` 평가액으로 이익을 계산하고, 지분으로 수수료를 받습니다. 이 평가액이 현금화할 때의 수령액을 보장하지는 않습니다. 가치 조회에는 가스 150,000 한도를 적용합니다. 조회가 실패하면 해당 출금의 수수료를 면제하고 출금 대상 지분 전부를 수령인에게 전달합니다. 이후 상속 앱의 팩토리를 통해 그 지분을 현금화할 때 서비스 수수료를 다시 받지 않습니다.
- **USDC 금고의 WLD 보상:** 수령한 WLD 보상을 지급할 때 별도의 10% 수수료를 적용합니다. 직접 보내온 일반 자산은 제외하며, USDC 손실과 WLD 보상 수수료는 따로 계산합니다.

예치 전에는 현재 Re7 전략 수수료를 표시하며, 수수료가 바뀌면 내용을 다시 확인하고 동의해야 합니다. 별도 네트워크 비용은 World App의 기본 승인 화면에서 확인합니다.

## 개선 사항과 검증

홈·자산·플랜·도움말의 역할을 구분했습니다. 설정 과정에서 금액·수령인·연장 주기·수수료를 확인한 뒤 기본 승인 화면으로 넘어갑니다. 키보드를 사용할 때도 입력란과 버튼에 접근할 수 있도록 개선했습니다. 중단된 요청은 원래 거래 식별자와 영수증을 유지해 중복 예치나 출금을 방지합니다.

11월 9일 실제 안드로이드 World App에서 위 팩토리로 WLD·USDC 각각 0.01 최초 예치, 각각 0.01 추가 예치, 두 금고의 기한 연장, Morpho 전액 회수를 완료했습니다. 두 금고의 유휴 자산·전략 지분·원금 기록은 모두 0이 됐고 수령인은 해제됐습니다. 앱 프로세스를 종료하고 다시 로그인한 뒤에도 예치 중 상태와 종료 상태가 복구됐습니다.

11월 10일 최종 검증 결과입니다.

- 계약 테스트 476개, World Chain 블록 37478097 기반 포크 테스트 25개, 자금 처리 안전성 시나리오 12개, 영문·국문 UI 화면 구성 72개가 모두 통과했습니다.
- 운영 버전의 iOS 시뮬레이터 네이티브 테스트 호스트도 모의 지갑 승인을 사용한 테스트 4개를 모두 통과했습니다.
- 타입 검사와 린트가 통과했습니다. 확인한 운영 정적 파일 22개 모두 런타임 `e73e11f`의 고정 배포본과 일치했습니다.
- 계약 테스트는 접근 제어, 별도 수수료 수령인, 수수료 계산 시 원금 제외, 손실 기록, 최소 수령액, 현금·지분 정산, 재진입과 거래 롤백을 다룹니다. CI는 핵심 자산 보관 로직의 라인 커버리지 최소 90%를 검사합니다.
