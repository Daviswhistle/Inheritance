# 수익형 금고 로컬 검증

성과 수수료 **10%**, 계약 상한 10%로 검증했다. 이 기록은 로컬 구현과
검증 결과이며, 새 계약 배포·서비스 활성화·스토어 승인을 뜻하지 않는다.
현재 WLD 금고의 사업성은 [설계 문서](MORPHO_YIELD.md#현재-wld-금고의-사업성)를
참고한다. 기본 대출이자는 당시 매우 낮았지만 일반 WLD 캠페인 보상은 별도로
발생한다. 실제 수령한 보상을 포함해 순이익의 10%를 수취하며, 인증 사용자 추가
보상이나 고정 수익률을 약속하지 않는다. USDC로 자산을 바꾸지 않는다.

현금 상속의 실제 포크 gateway 실행은 **367830 gas**, 정식 Distributor 보상 청구와
재예치는 **416468 gas**였다. 보상 포크의 root는 로컬에 주입한 증명이며 실제 캠페인
적립을 입증하지 않는다. 실패한 외부 호출이
gas를 소비하는 경우에는 계약을 750000 gas로 직접 실행해 지분 fallback을 검증했다.
자동 실행기는 20% 추정 여유분까지 포함하도록 최대 gas를 850000으로 설정한다.
두 외부 호출이 가스를 소진하는 경우도 실제 실행기에서 전송·정산하며, 기존 하루
ETH 한도와 OP 예비금은 유지한다.
팩토리 runtime 6118 bytes, 고정 배포 helper 20338 bytes, 개인 금고 17972 bytes로
EIP-170 한도 내에 있다. constructor에서 helper를 함께 만들며 helper의 생성 권한은
그 팩토리로 고정한다. 고정 compiler·optimizer 설정과 배포 artifact의 정확한 일치를 유지한다.

배포 helper의 dry-run은 기존 운영자 지갑과 수취 주소, 10% 수수료, 고정 Re7 WLD,
전체 실행·L1 비용 상한 0.000015 ETH, 예측 주소와 생성 runtime 일치를 확인했다.
예상 실행 gas는 5863512, 실행·L1 합계 예약 비용은 약 0.0000102 ETH였다.
이는 무전송 모의 실행이다. 실제 배포에는 독립 코드 리뷰와 명시한 활성화 조건이 필요하다.

UI 캡처와 HTML/CSS로 새 스토어 이미지를 만들었다. 수익형 예시에는 10% 수수료,
원금 손실과 유동성 제약을 함께 표시했다. 예시 잔액은 수익률 약속이 아니다.
스토어 설명 초안은 `MORPHO_STORE_METADATA.json`이며 포털에는 아직 적용하지 않았다.

레지스트리 조회 결과는 지갑별로 구분하며, 실패한 팩토리의 이전 확인 항목을 유지한다.
성공한 조회에서 빈 슬롯이 확인된 경우에만 항목을 제거한다. 화면에 실패와 재시도를
표시하고 활성 화면에서는 30초마다 재조회한다. 변경 후 기존 기본 금고 선택 13개와
역할 복구 5개를 다시 확인했다.

금고의 실제 지분·idle WLD는 평가·유동성 조회와 별도로 읽는다. 최초 평가 조회가
실패해도 소유자의 지분 회수, 상속인의 지급 완료, 해제한 금고 회수가 가능하다. 확인된 idle WLD는
캐시된 평가액보다 커도 All 버튼과 출금 검증에 반영해 별도로 회수할 수 있다.
수익형 서비스를 구성하면 사이클당 조회 최대 2개·지급 최대 1개로 제한한다.
더 큰 batch를 설정해도 실제 한도를 적용하고 나머지 지급은 다음 사이클에서 진행한다.

실제 휴대전화의 World App 승인·예치·출금, 새 계약 메인넷 실행, 실제 7일 자동 지급은
이 로컬 검증의 증거가 아니다. 독립된 제3자 보안 감사도 수행하지 않았다.
