# Privacy

- The app does not collect personal data beyond what is required to display the UI and interact with World App MiniKit.
- World ID verification (if enabled) happens via MiniKit and returns only the verification result required for gating features.
- No wallet private data is collected; balances are fetched from public RPC.

Analytics
- If analytics are enabled in deployment, they must be anonymized and exclude wallet addresses by default. This reference repo ships with analytics disabled.
